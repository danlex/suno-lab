## What Is This?

Suno AI generates complete songs (vocals, instruments, lyrics) from text prompts in under 60 seconds. But getting from a generic output to something that sounds intentional — cinematic, emotionally precise, structurally coherent — requires serious prompt engineering.

This repository documents that process: **100 experiments** spanning orchestral, cinematic, electronic-orchestral fusion, and experimental music. Each prompt is versioned, tagged, and annotated with notes about what worked, what didn't, and why.

## What You'll Find

- **Versioned prompts** — iterative refinements showing how small changes in wording affect output (e.g., `longer-than-light` spans v1 through v24)
- **Style descriptions** — flowing, conversational style prompts optimized for Suno v5.5 (up to 1,000 characters)
- **Structural metatags** — `[Intro]`, `[Verse]`, `[Chorus]`, `[Silence]`, `[Big Finish]`, and more to control song structure
- **Engineering notes** — what each experiment tests (frisson triggers, silence-before-climax, key modulation, instrument control)
- **Full-text search** — filter by title, tag, key, BPM, style, or instrument in the live archive

## Key Techniques Explored

| Technique | Description |
|-----------|-------------|
| Silence before climax | Build to 80%, drop to near-silence, then deliver a climax that exceeds expectations |
| Key modulation at climax | Half-step up (e.g., D Major to Eb Major) after silence for a frisson multiplier |
| Three-layer instrument control | Genre anchor + specify instruments + negative prompts + exclude styles |
| Conversational style prompts | Flowing descriptions instead of comma-separated tags (v5.5 optimization) |
| Psychoacoustic triggers | Shepard tones, glass harmonica spatial disorientation, spectral music techniques |

## How It Works

1. Prompts are authored as YAML files in `prompts/`
2. `scripts/build_site.py` compiles them into `docs/songs.json`
3. `docs/index.html` renders the searchable archive via GitHub Pages
4. Songs are generated at [suno.com/create](https://suno.com/create) using Custom Mode

### Prompt Format

```yaml
name: "song-name"
version: 1
style: "Flowing conversational style description..."
title: "Song Title"
lyrics: |
  [Intro]
  ...
  [Chorus]
  ...
  [End]
instrumental: true
exclude_styles: "Arabic, rock, electronic"
notes: "What this experiment tests"
tags: [orchestral, cinematic, silence-before-climax]
```

## Tech Stack

- **Prompt format:** YAML with structured metatags
- **Site generator:** Python (`scripts/build_site.py`)
- **Frontend:** Vanilla HTML/CSS/JS, dark theme, client-side search
- **Hosting:** GitHub Pages
- **AI model:** Suno v5.5 (March 2026)
- **Automation:** Claude Code with browser automation for prompt submission

## Repository Structure

```

  index.html       # Searchable archive UI
  songs.json       # Compiled prompt data

```
